# Personal Portfolio Website

This is a responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript**. It showcases my profile, experience, projects, and contact information.

## 🖥️ Live Demo

Check it out live here: [Sri Hasitha Gudipati Portfolio](https://srihasithagudipati.netlify.app/)

## 🚀 Features

- Fully responsive design (mobile-friendly)
- Hamburger menu for small screens
- Smooth scroll navigation
- Downloadable resume
- Project showcase with links
- Contact section with email and LinkedIn

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Poppins)
